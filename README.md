# Ranas en Rebelión 🐸

Shooter 2D humorístico inspirado en la idea de crear un juego rápido: mundo que avanza, alcantarillas sucias, enemigos, armas y una tienda de mejoras.

## Incluye
- Elección entre rana maga, espadachina y de magia oscura.
- Niveles con escenarios nuevos cada 5 niveles.
- Alcantarillas, pantano, ciudad y templo lunar.
- Ranas aliadas controladas por bots.
- Humanos y robots jefes.
- Tienda de escopeta, metralleta y burbujas gigantes.
- Controles táctiles y teclado.

## Cómo jugar
- Flechas o botones táctiles para mover la rana.
- Espacio o botón de ataque para disparar.
- Tecla E o botón de poder para usar el ataque especial.
