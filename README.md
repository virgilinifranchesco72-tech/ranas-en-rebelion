# Ranas en Rebelión 🐸

Shooter 2D humorístico hecho con HTML, CSS y JavaScript, pensado para jugar desde el celular.

## Cómo jugar
- Flechas del teclado o botones táctiles para mover la rana.
- Espacio o botón 🫧 para disparar.
- Eliminá a los humanos antes de que te alcancen.

## Publicarlo con GitHub Pages
1. Subí estos archivos a un repositorio de GitHub.
2. Entrá en **Settings > Pages**.
3. Elegí la rama `main` y la carpeta `/root`.
4. Guardá y abrí el enlace que GitHub genere.
